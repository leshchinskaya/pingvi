Pingvi 0.7.0 beta 5 — предварительная сборка для коллег

Требования
• Mac с Apple Silicon и macOS 14 или новее. Intel не поддерживается этой сборкой.
• Python 3.13.15 включён в приложение. Xcode, Homebrew и отдельный Python для запуска не нужны.
• Установленный и авторизованный Claude Code или Codex CLI.
• herdr для сессий herdr и создания новых диалогов.
• Обычные вкладки поддерживаются в Apple Terminal. iTerm/Ghostty пока не подключены.

Установка
1. Перетащите Pingvi в Applications. Если приложение уже запущено, сначала завершите его через Cmd+Q.
2. Извлеките DMG и откройте Pingvi из Applications.
3. Если macOS блокирует неизвестного разработчика: после попытки запуска откройте Системные настройки → Конфиденциальность и безопасность → Всё равно открыть. Корпоративные ограничения могут запрещать это действие.
4. В Pingvi нажмите «Настроить». Проверьте подключения. Если herdr или агент не найден, укажите полный путь в «Пути к программам».
5. Для Claude нажмите «Подключить / обновить» и перезапустите старые сессии Claude.
6. Для обычного Terminal включите чтение вкладок и разрешите автоматизацию. Разрешите уведомления и проверьте тестовый баннер.
7. Получите тестовый вопрос в отдельной сессии, ответьте через Pingvi и проверьте продолжение в исходном окне.

Ограничения
Сборка с локальной ad-hoc подписью, без notarization Apple, если автор явно не сообщил обратное. Полная проверка на другом Mac ещё требуется.
Ответы через терминал распознаются по экрану. «Доставка не подтверждена» означает, что нужно проверить исходное окно перед повтором. Автоматических повторов нет.
Настройки → Основные → Чат в Pingvi включает экспериментальную переписку.
Python входит в приложение. Установка/авторизация CLI агентов и herdr выполняется отдельно.

Обновление и отключение
Завершите Pingvi, замените приложение в Applications, откройте новую версию. После обновления нажмите «Подключить / обновить» для Claude.
Перед удалением Pingvi отключите Claude в настройках подключений и перезапустите сессии Claude. Затем завершите и удалите приложение.
Настройки и локальные данные сохраняются при замене приложения.

Данные
Очередь, черновики и квитанции отправки с текстом хранятся в ~/Library/Application Support/AgentAttention. Журналы агентов читаются локально. Резервные копии настроек Claude находятся рядом с settings.json.
Не отправляйте коллегам эту папку или журналы рабочих диалогов. Для отзыва достаточно версии Pingvi, версии macOS, источника сессии, шагов и фактического результата без секретов.

Открытие неподписанной сборки: https://support.apple.com/guide/mac-help/mh40616/mac

Управление данными
В настройках → Данные можно отдельно удалить черновики чата, черновики ответов на вопросы и тексты обработанных отправок. Каждое действие требует подтверждения. Неподтверждённые отправки и защита от повторной отправки сохраняются. Журналы агентов не удаляются.
Если Pingvi запущен из DMG, установка hooks и создание новых диалогов отключены до переноса приложения в Программы.
