# Данные и разрешения

Pingvi работает локально. Собственного сервера, учётной записи или телеметрии в приложении нет. CLI агентов продолжают использовать свои сервисы и настройки.

## Что хранится

В `~/Library/Application Support/AgentAttention` находятся очередь, названия сессий, черновики, напоминания, hooks и сведения об отправке. Квитанции отправки могут содержать текст сообщения. Доступная история читается из исходных журналов агентов.

Основные файлы состояния создаются с правами 0600, каталог — 0700. Это ограничение доступа на уровне файловой системы, а не отдельное шифрование.

## Очистка

В «Настройки → Данные» доступны отдельные действия:

- Удалить черновики чата и недавние папки.
- Удалить текст и выбранные варианты черновиков ответов на вопросы.
- Удалить тексты обработанных отправок.

Каждое действие требует подтверждения. Неподтверждённые отправки сохраняются, чтобы их можно было проверить. Служебные записи без текста остаются для защиты от повторной отправки. Очистка Pingvi не удаляет историю из журналов Claude/Codex и не прекращает сессии агентов.

## Подключение Claude

По нажатию «Подключить / обновить» приложение добавляет собственные hooks в настройки Claude, сохраняя остальные записи. Перед изменением создаётся резервная копия `settings.json.attention-backup-*` рядом с файлом настроек. Кнопка «Отключить» удаляет записи Pingvi; существующие сессии после этого нужно перезапустить.

## Системные разрешения

Уведомления нужны для баннеров, Automation — для работы с Apple Terminal, Accessibility — для списка при наведении на Dock. В вопросах и уведомлениях может отображаться текст задачи: учитывайте это при демонстрации экрана и публикации скриншотов.

В issue прикладывайте минимальный пример с вымышленными данными. Не загружайте целиком каталог состояния или журналы рабочих агентов.

Для продолжения чтения Pingvi хранит идентификаторы сообщений и последний контекст терминала на момент ответа. Контекст удаляется вместе с черновиками ответов на вопросы, а закладки — вместе с черновиками чата. Детали запросов разрешений показываются полностью.
